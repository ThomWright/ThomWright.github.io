# ThomWright.github.io

## Developing

### Dependencies

For running locally, see the [Jekyll dependencies](https://jekyllrb.com/docs/installation/).

```bash
gem install bundler
bundle install
```

### Run

On your machine:

`jekyll serve --watch --drafts -H 127.0.0.1 -P 4000`

Prefix with `bundle exec` if you don't have `jekyll` installed and on your PATH.

### Generate the syntax highlighting styles

The light and dark themes are generated by Rouge and loaded for the matching `prefers-color-scheme`.

```bash
rougify style github > public/css/syntax/highlight.css
docker run --rm ruby:3.3-alpine sh -c "gem install rouge -v '~> 4.0' >/dev/null 2>&1 && rougify style github.dark" > public/css/syntax/highlight-dark.css
```

The bundled Rouge is too old to have `github.dark`, hence Docker for the dark theme. Rouge 5 needs a native extension that doesn't build on the Alpine image, hence `~> 4.0`.
