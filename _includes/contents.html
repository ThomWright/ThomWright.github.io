{% comment %} The page's contents: links to its sections and subsections. On wide screens they sit in the left margin. On narrow screens they are a collapsed bar above the text, which sticks to the top of the screen while reading. Only long pages with several sections get contents, and this renders nothing for the rest. A short page can be taken in at a glance, so contents would only get in the way. Place this directly before the element holding the page's content, so the margin version lines up with the start of the text.
